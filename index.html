The Lab

I run a 35B model on a $300 GPU — and write down what breaks.

The most interesting part of the studio isn't the cloud models everyone has. It's the local crew, and the honest field notes from making them do real work. Green ≠ correct. Divide labor by novelty, not difficulty. The receipts are here.

Read the field notes →
# qwen-as-junior, opus-as-gate
✔ T08 mirror form pattern → clean
✔ T12 reuse test scaffold → clean
✘ T05 archive blanked name/color (passed its own tests)
⚠ T13 detail screen won't compile — "tests pass"
request (128055 tokens) exceeds context (128000)
→ rule: always verify yourself. green ≠ correct.
01

Green ≠ correct

The local worker exits 0 and reports "all tests pass" while real data-loss bugs ship. I run analyze, format, and tests myself, every task. Trust nothing the junior says.

02

Divide by novelty, not difficulty

Qwen is great at imitation, bad at invention. So Opus builds the first-of-a-kind, and the local model extends the pattern — always pointed at a fresh in-repo example.

03

Mind the context cliff

The dominant failure on long tasks wasn't capability — it was silent context overflow. Small tasks, a priority read-list, and a reference skeleton for the one risky API call.
